# Cinematic Video Scripting

## Goal

Turn an idea into a script that is designed to be watched, not merely read. Treat dialogue, visuals, camera, movement, editing, sound, text, performance, and platform constraints as one system.

Do not add cinematic complexity for its own sake. Every shot or edit must serve at least one purpose: comprehension, emotion, proof, novelty, rhythm, continuity, product clarity, or retention.

## Required inputs

Use what the user provides. Infer safe defaults when details are absent and the choice is reversible. Do not block on optional information.

Useful inputs include:
- objective and CTA
- audience
- platform and aspect ratio
- target duration
- subject/product
- available locations, people, props, and footage
- creator/brand voice
- production constraints
- whether footage is live-action, AI-generated, screen-recorded, or mixed

Never invent product claims, testimonials, prices, certifications, results, or factual demonstrations.

## Workflow

### 1. Define the viewing job

Identify:
- what must stop the scroll
- what the viewer should understand or feel
- what evidence or demonstration earns belief
- what action, if any, should follow

For short-form content, design the opening as a visual-and-verbal hook rather than relying on dialogue alone.

### 2. Build the narrative spine

Use the structure that best fits the content. Possible beats include:
HOOK → CONTEXT → TENSION/QUESTION → DEVELOPMENT/PROOF → PAYOFF → CTA.

Do not force this structure when another narrative form is better.

Every beat must advance the video. Remove repetition, throat-clearing, generic intros, and filler.

### 3. Design visual beats with the script

For each meaningful beat, decide:
- spoken line / narration / silence
- primary visual
- shot size and angle
- subject/action
- camera movement when useful
- B-roll or insert
- on-screen text when useful
- sound/music cue when useful
- transition/edit intention
- approximate duration

Use `references/shot-library.md` to select shots intentionally.

Do not use random shot variation. Match visual grammar to narrative purpose.

### 4. Create a shot rhythm

Avoid visually static stretches unless stillness is deliberate.

Vary:
- scale
- angle
- foreground/background relationship
- subject position
- movement
- visual information

Prefer motivated cuts. Cut because information, emotion, emphasis, location, perspective, or rhythm changes.

For short-form content, introduce pattern changes often enough to maintain attention without turning the edit into visual noise.

### 5. Preserve continuity

Check:
- screen direction
- eyelines
- subject position
- props
- wardrobe
- lighting
- time-of-day logic
- hand/object state
- action continuity
- spoken continuity

If continuity intentionally changes, make the transition understandable.

### 6. Design for the platform

Adapt composition and pacing to the intended surface.

For vertical video:
- protect the center-safe viewing area
- avoid important information beneath interface overlays
- favor readable close and medium compositions
- ensure text remains readable on a phone

For horizontal/long-form:
- allow longer visual development when appropriate
- use establishing shots and spatial relationships more freely

Never assume one edit should simply be cropped into every platform.

### 7. Design sound

Specify only meaningful audio direction:
- dialogue
- voiceover
- room tone
- sound effects
- music changes
- deliberate silence

Use sound bridges and J/L-style transitions when they improve flow.

Do not make the script dependent on copyrighted music unless the user has appropriate rights.

### 8. Design text and captions

Assume many viewers may initially watch without sound.

Critical meaning should remain understandable through visuals and/or captions.

On-screen text must:
- be concise
- add information rather than duplicate every spoken word unnecessarily
- remain readable
- respect safe zones
- have sufficient contrast

### 9. Production feasibility

Distinguish:
- essential shots
- preferred shots
- optional enhancement shots

When resources are constrained, preserve the narrative and proof shots before decorative cinematography.

If AI generation is used, specify observable visual properties rather than relying only on camera jargon: subject, environment, composition, lens feel, lighting, movement, action, duration, continuity anchors, and exclusions.

### 10. Final editorial pass

Check:
- Can the first beat earn attention without misleading the viewer?
- Does each shot have a purpose?
- Is there visual proof where the script makes an observable claim?
- Are there unnecessary repeated angles?
- Is the pacing appropriate for the platform and subject?
- Can the story be understood with sound off where relevant?
- Does the ending resolve the promise established by the opening?
- Is the CTA proportionate and natural?
- Can the planned footage actually be produced?

## Output contract

Unless the user asks for another format, produce:

### Creative Direction
One concise statement describing the video's visual/narrative approach.

### Script + Visual Plan
Use a production table with:
`Time | Audio/Dialogue | Visual Action | Shot/Camera | On-Screen Text | Edit/Sound`

### Shot List
List required shots in capture order when that is more efficient than script order.

### Continuity Anchors
Only include continuity details that production must preserve.

### Production Notes
Include only actionable constraints, props, lighting, location, performance, or post-production notes.

For very simple videos, collapse the format rather than manufacturing unnecessary production bureaucracy.

## Quality rules

Always:
- preserve the creator's authentic voice
- show rather than merely tell when possible
- use visual evidence for demonstrations
- make the hook truthful to the payoff
- prioritize clarity before novelty
- keep shot choices intentional
- account for accessibility
- preserve brand/product accuracy
- distinguish facts from creative claims
- make scripts executable by a human crew or video-generation system

Never:
- add shots merely to use more shot types
- use camera movement without narrative motivation
- overload every second with effects
- manufacture fake social proof
- hide required disclosures
- use deceptive before/after storytelling
- sacrifice comprehension for cinematic style

## Definition of done

A script is complete only when a producer, creator, editor, or capable video-generation system can understand:
1. what is said,
2. what is seen,
3. how it is framed,
4. what changes over time,
5. how the edit should flow,
6. what must remain continuous,
7. what is essential versus optional,
8. and how the finished video serves its intended audience and platform.
