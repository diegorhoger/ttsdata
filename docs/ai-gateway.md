# AI gateway v1

AI is optional. `AI_ENABLED=true`, the database global control, tenant control and user control must all be enabled. Platform mode additionally requires a paid plan and an explicit deployment-managed platform entitlement. Deterministic analytics does not import or call a provider. FakeAIProvider exercises the exact provider-neutral contract offline.

The API exposes `/api/ai/disclosure`, `/consent`, `/keys`, `/keys/byok` (replace/rotate), `/keys/byok/validate`, `/keys/byok/disable`, `/keys/byok/delete`, `/controls`, `/workspace-controls`, `/usage`, and `/generate`. Consent is versioned; older consent fails closed. All identities come from the session, never a caller-supplied workspace/user. HTTPS is mandatory for key entry/validation. Configure trusted TLS-terminating proxy CIDRs explicitly through `TRUSTED_PROXY_CIDRS`; never trust arbitrary forwarded headers.

Set `AI_ENCRYPTION_KEYS` to a JSON keyring of integer versions and base64-encoded 32-byte master keys, and `AI_ENCRYPTION_VERSION` to the active version. Retain older master versions until every stored credential is replaced. AES-256-GCM binds ciphertext to workspace, user, mode and provider. Clients receive only irreversible masked fingerprints. Disable/delete stops subsequent dispatches; calls already dispatched may complete. Delete immediately removes encrypted material from active storage. Deployment backups must expire within 30 days; operators must enforce this backup policy. No key material is copied into audit or ledger.

Platform keys are provisioned only by a deployment operator, encrypted in the same tenant/user-isolated store, not accepted through user APIs. Run `node --import tsx apps/api/scripts/provision-ai.ts` with `DATABASE_URL`, encryption keyring, `AI_PROVISION_WORKSPACE_ID`, `AI_PROVISION_USER_ID`, and optionally `AI_PLATFORM_OPENROUTER_KEY`. Provisioning validates the key against OpenRouter before replacement. `AI_PLATFORM_OPERATION` selects `replace` (default), `disable`, or `delete`. Explicit booleans `AI_ENABLE_GLOBAL`, `AI_ENABLE_TENANT`, `AI_ENABLE_USER`, `AI_ENABLE_PLATFORM` control activation; absent flags disable those controls. Never pass secrets as command-line arguments. Global controls are not user-modifiable. BYOK HTTP routes cannot mutate platform credentials.

Only the selected content's latest authorized numeric views/clicks/orders/conversion is sent. No IDs, arbitrary prose, URLs, account fields or access tokens are sent. Inferred/unavailable readings are null. The disclosure identifies OpenRouter/downstream processors, variable retention, default ZDR, in-memory caching caveat, and the selected account's cost responsibility. Response reasoning fields are discarded; only the server-owned versioned summary schema is returned. Prompts, outputs and reasoning are never persisted in metadata tables.

OpenRouter discovery is cached for five minutes. Expired discovery failure never reuses stale capabilities. Requests require structured-output parameters, deny data collection, honor consent ZDR, apply price caps, and disable provider/model fallback. A BYOK failure never selects platform credits. Up to three attempts are reserved in advance; only explicit rate-limit/503 rejection can retry on the same key/model. Ambiguous network failure/timeouts never retry. Circuit state is per-process, tenant/user/key-revision partitioned; durable user budgets are enforced across processes using transaction advisory locks. The ledger preserves provider usage/cost or explicit null/unavailable. Unknown charges retain the conservative reservation, never become free calls. Failed precharge operations release cost/token reservations. Daily accounting uses database UTC-day boundaries; request counts remain reserved conservatively. No transaction spans provider I/O.

The ledger is append-only and versioned, with correlation ID, key mode, provider/model, prompt/schema versions, latency, finish reason, attempts, usage and cost-source metadata. Repeated correlation IDs never produce another call; finalization is idempotent. Reservations survive process failures and expire for concurrency after two minutes, retaining conservative daily spend. User/workspace deletion may cascade ledger/audit deletion; direct mutations while the identity exists are rejected. No model-output repair makes a second paid request: invalid/truncated output fails closed.

Official protocol references: [structured outputs](https://openrouter.ai/docs/guides/features/structured-outputs), [ZDR](https://openrouter.ai/docs/guides/features/zdr), [models](https://openrouter.ai/docs/api/api-reference/models/list-all-models-and-their-properties), [key limits](https://openrouter.ai/docs/api_reference/limits).
