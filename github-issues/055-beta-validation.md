### User story

As the platform, I need to recruit and validate beta users with 20-50 Brazilian creators.

### Requirements

- Recruitment criteria
- Core journey definition (connect, sync, view insights, save/alert)
- Activation and retention events
- Qualitative interview script
- Usefulness scoring
- Pricing experiment
- Exit thresholds

### Acceptance criteria

- [ ] 20-50 creators complete the core journey
- [ ] Pricing experiment produces interpretable results
- [ ] A documented go, iterate, or stop decision is issued
