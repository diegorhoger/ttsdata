### User story

As a new user, I want to connect my TikTok account immediately so that I get personalized insights from day one.

### Requirements

- Prompt TikTok OAuth during onboarding
- Show value before requiring connection
- Allow skip without penalty
- No achievements or rewards tied to data contribution
- Clear separation: connecting for personal analytics vs. optional contribution to aggregate analytics

### Acceptance criteria

- [ ] User can connect, skip, or continue without penalty
- [ ] Connection and contribution consent are separate
- [ ] Declining contribution does not restrict personal analytics
- [ ] Consent text and policy version are recorded
